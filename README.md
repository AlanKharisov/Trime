# Trime Agency

A senior 4-person digital agency building fast, beautiful, search-optimised products — from concept to launch.

🌐 **Website:** [trime.org](https://trime.org)

## What we do

- Full-Stack Development
- UI/UX Design
- SEO & Performance
- Branding & Identity

## Tech stack

- **Frontend:** [Next.js](https://nextjs.org/), [React](https://react.dev/), [TypeScript](https://www.typescriptlang.org/), [Tailwind CSS](https://tailwindcss.com/)
- **Deployment:** GitHub Pages via GitHub Actions

## Getting started

```bash
# Install all dependencies
npm run install:all

# Start the frontend (and backend, if present)
npm run dev

# Build for production
npm run build
```
